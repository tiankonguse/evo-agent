┌─ THE 5 CORE PATTERNS ─────────────────────────────────────────────────────┐
│                                                                             │
│  1. TOOL REGISTRY (tool.go)                                                │
│     ├─ What: Central registry for all tools                                │
│     ├─ How: Each tool calls Register() in init()                           │
│     ├─ Key Types: ToolDef, Handler, registry map                           │
│     └─ Benefit: Decoupled, no central file needed                          │
│                                                                             │
│  2. TASK TOOL (task.go)                                                    │
│     ├─ What: Spawn subagent with fresh context                             │
│     ├─ How: Callback injection (var subagentRunner)                        │
│     ├─ Key: Avoids import cycle (agent ↔ tools)                            │
│     └─ Result: Summary text returned to parent                             │
│                                                                             │
│  3. TODO MANAGER (todo.go)                                                 │
│     ├─ What: Session plan with stale detection                             │
│     ├─ State: GlobalTodo singleton (RWMutex)                               │
│     ├─ Logic: Round counter → reminder after 3 turns                       │
│     └─ Integration: Injected into tool results by agent loop               │
│                                                                             │
│  4. PLAN MANAGER (plan.go)                                                 │
│     ├─ What: Persistent task graph on disk                                 │
│     ├─ Storage: .tasks/todo/ and .tasks/done/                              │
│     ├─ Structure: plan.md + task_N.json files                              │
│     └─ Graph: Bidirectional dependencies (BlockedBy ↔ Blocks)              │
│                                                                             │
│  5. EXECUTOR (executor.go)                                                 │
│     ├─ What: Single function that processes all tool calls                 │
│     ├─ Flow: Iterate blocks → Dispatch → Collect → Persist                 │
│     ├─ Output: Large files saved, paths returned inline                    │
│     └─ Errors: Set isError flag on results                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ AGENT LOOP FLOW ─────────────────────────────────────────────────────────┐
│                                                                             │
│  Loop Iteration:                                                            │
│                                                                             │
│    1. autoCompact()                                                         │
│       └─ Micro-compact recent results                                      │
│       └─ Full LLM summarization if needed                                  │
│                                                                             │
│    2. client.Messages.New(system, messages, tools)                         │
│       └─ Call LLM with system prompt + conversation + all tools            │
│                                                                             │
│    3. Append assistant response to history                                 │
│       └─ Messages now has assistant's thinking + tool calls                │
│                                                                             │
│    4. toolResults := Execute(response.Content)                             │
│       └─ Dispatch all tool calls                                           │
│       └─ Collect results + persist large outputs                           │
│                                                                             │
│    5. Check todo usage → inject reminder                                   │
│       └─ Did model call todo tool? Reset counter.                          │
│       └─ Stale? Append reminder to toolResults.                            │
│                                                                             │
│    6. Append tool results as USER message                                  │
│       └─ state.Messages = append(state.Messages,                           │
│              NewUserMessage(toolResults...))                               │
│                                                                             │
│    7. Loop continues if toolResults != empty                               │
│       └─ Go to step 1 if model called tools                                │
│       └─ Return if model stopped requesting tools                          │
│                                                                             │
│  KEY: Tool results are appended as USER message, not assistant!            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ SINGLETON STATE MANAGERS ────────────────────────────────────────────────┐
│                                                                            │
│  GlobalTodo (in-memory, session-scoped)                                   │
│  ├─ Type: *todoManager with RWMutex                                      │
│  ├─ State: items[], roundsSinceUpdate int                                 │
│  ├─ Lifecycle: Empty at startup, updated via todo tool                    │
│  └─ Reminder: "Refresh plan" after 3 turns without update                 │
│                                                                            │
│  GlobalPlan (persistent, disk-based)                                      │
│  ├─ Type: *PlanManager with RWMutex                                      │
│  ├─ Storage: .tasks/todo/ and .tasks/done/                                │
│  ├─ Structure: plan.md + task_N.json files                                │
│  ├─ Dependencies: Bidirectional (task 1 blocks task 2 ↔ task 2 blocked)   │
│  └─ Operations: Create, TaskCreate, TaskUpdate, TaskList, Complete        │
│                                                                            │
│  GlobalMemory (persistent, SQLite)                                        │
│  ├─ Type: *MemoryManager with RWMutex                                    │
│  ├─ Storage: .memories database                                           │
│  └─ Used by: remember tool for session context                            │
│                                                                            │
│  Agent.Messages (stack-scoped, append-only)                               │
│  ├─ Type: []MessageParam                                                  │
│  ├─ Lifecycle: Grows during agent loop                                    │
│  └─ Compact: Summarized when size exceeds limit                           │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ ERROR HANDLING ──────────────────────────────────────────────────────────┐
│                                                                            │
│  Scenario                         Handling                Result         │
│  ─────────────────────────────────────────────────────────────────────   │
│  Invalid tool input JSON          Unmarshal error        (msg, err) →    │
│                                   return ("", err)       error flag set   │
│                                                                            │
│  Tool logic error                 Catch in Execute()     (msg, err) →    │
│                                   return (err, nil)      error flag set   │
│                                                                            │
│  Tool not registered              Dispatch() silent      return ""        │
│                                   return ("", nil)       model retries    │
│                                                                            │
│  Dependency uninitialized         Return error message   ("Error: ...", nil)
│  (e.g., subagentRunner nil)       visible to model                       │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ THREAD SAFETY ───────────────────────────────────────────────────────────┐
│                                                                            │
│  State              Sync Mechanism      Usage Pattern                     │
│  ──────────────────────────────────────────────────────────────────────   │
│  GlobalTodo         sync.RWMutex        Read: Reminder()                 │
│                                         Write: Update()                   │
│                                         Used by: Agent loop + TUI         │
│                                                                            │
│  GlobalPlan         sync.RWMutex        Lock entire file operation       │
│                                         Used by: Tool handlers            │
│                                                                            │
│  Agent.Messages     Append-only         Last writer wins                  │
│                     (no lock)           Safe for append, read-only view   │
│                                                                            │
│  CompactState       Immutable            Passed by value                   │
│                     (value type)        No synchronization needed         │
│                                                                            │
